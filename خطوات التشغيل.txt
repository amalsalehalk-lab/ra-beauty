RA Beauty — النسخة السحابية (كل الفريق على نفس البيانات)
==========================================================

المطلوب مرة وحدة فقط، وبعدها كل شي يشتغل لحاله.

الخطوة 1 — إنشاء قاعدة البيانات (5 دقائق)
  1. ادخلي supabase.com واعملي حساب مجاني ← New project.
  2. اختاري اسم المشروع وكلمة مرور لقاعدة البيانات (احفظيها عندك)، والمنطقة: اختاري الأقرب (Frankfurt أو Singapore).
  3. انتظري لين يخلص التجهيز (دقيقتين تقريباً).

الخطوة 2 — تركيب الجداول
  1. من القائمة اليسار: SQL Editor ← New query.
  2. افتحي ملف schema.sql الموجود بهذا المجلد، انسخي محتواه كامل والصقيه، ثم Run.
  3. لازم تطلع رسالة Success.

الخطوة 3 — إيقاف تأكيد الإيميل (مهم)
  Authentication ← Sign In / Providers ← Email ← عطّلي خيار "Confirm email" ← Save.
  (لأن حسابات الفريق تستخدم أسماء مستخدمين، مو إيميلات حقيقية.)

الخطوة 4 — إنشاء حسابك أنتِ (أول حساب = مالكة تلقائياً)
  Authentication ← Users ← Add user ← Create new user:
     Email:    amal@ra-beauty.app
     Password: كلمة مرور قوية تختارينها
     فعّلي خيار Auto Confirm User إذا ظهر.
  ملاحظة: صيغة الإيميل لازم تكون بالضبط: اسم_المستخدم@ra-beauty.app

الخطوة 5 — نشر التطبيق
  1. افتحي app.netlify.com/drop واسحبي هذا المجلد كامل داخل المربع.
  2. بيطلع لك رابط مثل: https://ra-beauty.netlify.app (تقدرين تغيرين الاسم بعد التسجيل المجاني).

الخطوة 6 — أول دخول
  1. افتحي الرابط، بيطلب منك: Project URL و anon key.
     تلقينهم في: Supabase ← Project Settings ← API (انسخي Project URL و anon public).
  2. ادخلي باسم المستخدم: amal وكلمة المرور اللي اخترتيها.
  3. أول دخول بيعبّي قائمة الخدمات والمخزون الأساسية تلقائياً — عدّليها براحتك.

الخطوة 7 — إضافة ريم ومريم
  من داخل النظام: المستخدمين ← + مستخدمة جديدة. اكتبي الاسم واسم المستخدم وكلمة المرور واختاري الصلاحية.
  الحساب ينشأ فوراً، وتقدرين تعطينها البيانات وتدخل من أي جوال.

التثبيت على الجوال
  آيفون: افتحي الرابط في Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.
  أندرويد: Chrome ← القائمة ← تثبيت التطبيق.

كيف تشتغل المزامنة
  - كل تعديل ينحفظ على السحابة مباشرة، والنظام يحدّث نفسه كل 20 ثانية.
  - تحت اسمك في القائمة يظهر "✓ متزامن" مع وقت آخر تحديث — اضغطي عليه للتحديث الفوري.
  - لو صار خطأ اتصال، بيظهر تنبيه أحمر.

ملاحظات صريحة
  - مفتاح anon مفتاح عام ومصمم للمتصفح؛ الحماية من قواعد الوصول (RLS) اللي ركّبناها: ما أحد يقرأ أو يكتب إلا حسابات فريقك.
  - فصل الصلاحيات بين المالكة والأخصائية مطبّق داخل التطبيق، وقاعدة البيانات تمنع أي شخص خارج الفريق تماماً وتمنع الأخصائية من حذف السجلات ومن تعديل صلاحيات المستخدمين.
  - لو نسيت وحدة كلمة مرورها: Supabase ← Authentication ← Users ← اختاري المستخدمة ← Reset/Update password.
  - "حذف المستخدمة" من داخل النظام يوقف دخولها؛ لحذفها نهائياً امسحيها من Authentication ← Users.
  - الباقة المجانية في Supabase تكفي حجم شغلك بمراحل. لو المشروع ما استُخدم أسبوع كامل ممكن يدخل في وضع سكون — يرجع بمجرد فتحه.
